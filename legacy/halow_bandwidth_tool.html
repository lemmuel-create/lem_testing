HaLow 6 dB bandwidth tool

FCC §15.247(a)(2) occupied-bandwidth checks: 6 dB / n dB bandwidth, 99% OBW, PSD and band edge. Simulate a signal or load a spectrum analyzer trace (CSV). Runs fully offline.
Header lines and extra columns are ignored; the first two numbers on each line are used. Most analyzers (Keysight, R&S, Anritsu, Signal Hound) export this format.

Method notes
  • n dB bandwidth: marker on the trace peak, then the outermost points where the trace falls to (peak − n dB), linearly interpolated. Per KDB 558074: RBW 100 kHz, VBW ≥ 3× RBW, peak detector, max hold.
  • 99% OBW: frequencies enclosing 99% of the integrated trace power (0.5% cut from each side).
  • Peak PSD: highest trace point scaled to 3 kHz as P3k = PRBW − 10·log10(RBW / 3 kHz). Valid when the trace was taken with an average (RMS) detector and the signal is wider than the RBW. Use the same method as your output-power measurement.
  • Band edge: highest trace level outside 902–928 MHz compared with the in-band peak. Only evaluated when the trace extends past a band edge. Restricted-band emissions (§15.205) need separate field-strength limits.
  • Simulator: spectrum shape is an idealized OFDM/FSK model; it is for training and sanity checks, not a substitute for lab data.
